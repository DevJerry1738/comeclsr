## 📞 Common Questions

### Q: Do I need to delete the old code?
**A**: Not immediately. The old `api/` directory can stay during Phase 2-3. It will be deleted once Edge Functions are complete (Phase 3).

### Q: Can I start Phase 2 now?
**A**: Yes! You can start Phase 2 immediately. Phase 2 doesn't depend on anything from Phase 1 except having Supabase credentials.

### Q: Will my current frontend break?
**A**: The frontend itself won't break. But pages that call the old tRPC API will fail. Phase 4 updates those, Phase 2 starts with auth.

### Q: How do I access the database?
**A**: Once you create a Supabase project, you can:
- Use Supabase Studio (web UI)
- Use `supabase` CLI
- Query via `supabase.from('table').select()`

### Q: What about data migration from MySQL?
**A**: That happens in Phase 6. For now, you can start fresh with Supabase.
